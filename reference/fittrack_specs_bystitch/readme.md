# FitTrack - Kinetic Noir (Expo)

Premium iOS fitness tracker featuring a futuristic, glassmorphic design. Built for high performance and visual excellence.

## 🚀 Get Started
1. `npm install`
2. `npx expo start`
3. Open in iOS Simulator or Expo Go.

## 🛠 Tech Stack
- **Core:** Expo SDK 54, React Native.
- **Styling:** NativeWind (Tailwind), Expo Blur.
- **Visuals:** React Native SVG, Reanimated.

## 📂 Architecture
- `/app`: Expo Router navigation (Tabs & Stacks).
- `/components`: UI (atoms) and Features (molecules).
- `/constants`: Theme tokens and Mock data.
- `/hooks`: Shared logic (state, sensors).
